# 多账号复盘与 Leader 指导 Agent

> AI Agent 实战题 · 第3题 · 可运行 Demo

## 项目简介

手搓一个多 X 账号管理 Agent，持续分析至少 3 个账号的内容和表现数据，自动识别每个账号最主要的 1-3 个问题，精准归因到 6 大维度，生成下周可执行的具体动作和 Leader 1on1 指导提纲，每日生成报告并对账号整体评分，同时持续追踪建议执行情况和效果，形成完整闭环。

## 核心能力

| 能力 | 说明 |
|------|------|
| **多账号诊断** | 自动识别每个账号最主要的 1-3 个问题，附带数据证据和影响评估 |
| **6维度精准归因** | 内容质量 / 选题 / 定位 / 发布节奏 / 互动 / 账号健康，规则引擎+LLM双保险 |
| **SMART行动建议** | 每个动作具体到可直接执行，有预期成果、时间节点、难度和所需资源 |
| **Leader指导提纲** | 结构化 1on1 沟通框架，先肯定再提问题，苏格拉底式提问引导，赋能而非批评 |
| **每日报告+评分** | 5维度加权评分（内容质量25%+选题20%+节奏15%+互动20%+增长20%），趋势一目了然 |
| **执行追踪闭环** | 追踪建议是否执行、执行后是否改善，未执行/无改善都有原因分析和改进建议 |

## 6 大问题维度

| 维度 | 判断标准 | 典型表现 |
|------|----------|----------|
| **内容质量** | 内容深度、原创性、表达清晰度 | 内容浅尝辄止、同质化严重、无信息量 |
| **选题** | 选题与受众匹配度、时效性、差异化 | 选题偏离定位、追热点但不相关、受众不感兴趣 |
| **定位** | 账号人设一致性、领域专注度、辨识度 | 内容领域跳跃、人设模糊、与竞品无差异 |
| **发布节奏** | 发布频率、时段、间隔规律 | 发布不稳定、断更频繁、时段不在受众活跃期 |
| **互动** | 回复率、响应速度、互动深度 | 不回复评论、回复模板化、不主动互动 |
| **账号健康** | 粉丝趋势、违规记录、平台权重 | 持续掉粉、被限流、有违规记录 |

### 环境要求

- Python 3.8+
- 无需额外依赖即可运行 Mock 模式 Demo

### 运行

```bash
cd multi_account_agent

# 完整周复盘 Demo（Mock模式，无需API Key）
python -m src.main --demo --mock

# 每日报告模式
python -m src.main --daily --mock

# 逐步运行
python -m src.main --step collect --mock    # 采集数据
python -m src.main --step diagnose --mock   # 诊断归因
python -m src.main --step action --mock     # 行动建议+指导提纲
python -m src.main --step report --mock     # 每日报告+评分
python -m src.main --step track --mock      # 执行追踪

# 真实LLM模式（配置API Key后）
export OPENAI_API_KEY="your-key"
python -m src.main --demo
```

## 核心设计亮点

### 1. 6维度精准归因

规则引擎基于指标阈值做初步归因（如发布频率变异系数>0.8→发布节奏问题），LLM 结合内容样本做深度根因分析，双保险确保归因准确。每个问题标注主因和次因，避免单一归因的偏差。

### 2. SMART 行动建议

每个动作都遵循 SMART 原则：
- **S**pecific：具体到"每条内容发布后2小时内回复前5条评论"，不说"加强互动"
- **M**easurable："回复率从0.4%提升到2%以上"
- **A**chievable：标注难度和所需资源，不超出能力范围
- **R**elevant：与诊断问题强关联，每个动作都有 linked_problem
- **T**ime-bound："下周一启动，全周执行"

### 3. Leader 指导提纲

不是简单的问题清单，而是完整的 1on1 沟通框架：
1. **开场与整体表现**（5分钟）：先肯定做得好的地方
2. **核心问题探讨**（10分钟）：苏格拉底式提问，引导对方自己发现问题
3. **行动共识**（8分钟）：与对方达成一致，不单方面下达
4. **资源支持**（5分钟）：了解困难，提供帮助
5. **收尾**（2分钟）：鼓励信心，约定下次沟通

同时附带 Do & Don't 注意事项，确保 1on1 是赋能会而非批斗会。

### 4. 5维度加权评分

- 内容质量 25%：内容深度、长度、互动表现
- 选题适配 20%：相关内容占比、类型多样性
- 发布节奏 15%：活跃天数、稳定性、发布频率
- 互动健康 20%：回复率、运营回复率、整体互动率
- 账号增长 20%：粉丝净增长、表现稳定性

评分等级：优秀(≥80) / 良好(≥65) / 一般(≥50) / 待改善(≥35) / 危急(<35)

### 5. 执行追踪闭环

追踪每个建议的 4 种状态：
- ✅ 已执行且有改善 → 固化为SOP，复制到其他账号
- ⚠️ 已执行但无改善 → 分析根因，调整动作方向
- 🟡 部分执行 → 肯定进展，分析未达标原因
- 🔴 未执行 → 深入了解真实障碍，降低执行门槛

每轮迭代都让诊断更精准、建议更可执行、执行率更高。

### 6. 人工审核合规

- Agent 只做分析和建议，**不自动操作账号**
- 诊断结果需 Leader 审核确认
- 行动建议需 Leader 与运营同学 1on1 共同确认
- 任何发布、回复、改资料等操作必须人工执行
- 符合题目"涉及对外发布或账号操作时，必须设置人工确认"的基本要求
